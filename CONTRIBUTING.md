# Contributing to One Word A Day

Thank you for contributing to One Word A Day!

## AI & Vocabulary Standards
- Daily words generated via OpenRouter / AI completions must include accurate definitions, parts of speech, and contextual example sentences.
- Ensure strict JSON validation in serverless API routes before responding to the frontend.

## Pull Request Guidelines
- Keep vanilla JS and CSS lightweight and performant.
- Ensure streak increment logic handles edge-case timezone transitions.
